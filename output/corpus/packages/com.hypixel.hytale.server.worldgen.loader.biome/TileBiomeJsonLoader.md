# TileBiomeJsonLoader

Type: class | Package: com.hypixel.hytale.server.worldgen.loader.biome | Extends: BiomeJsonLoader

public class TileBiomeJsonLoader extends BiomeJsonLoader

Loads a tile biome definition from JSON. Tile biomes are the primary biome type in the world generation system, constructed from the full set of biome sub-containers (terrain, layers, covers, water, etc.).
