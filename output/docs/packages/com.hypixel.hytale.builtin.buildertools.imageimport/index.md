**Package:** `com.hypixel.hytale.builtin.buildertools.imageimport`

Image-to-block import tool for creative mode builder tools. Provides the `/importimage` command and an interactive UI page for selecting images, configuring dimensions and orientation, and converting pixel colors to block types placed into the clipboard.

## Types

| Type | Kind | Description |
|---|---|---|
| [ImageImportCommand](ImageImportCommand.md) | class | Command (`/importimage`) that opens the image import UI page for the executing player. |
| [ImageImportPage](ImageImportPage.md) | class | Interactive custom UI page for importing images as block selections. |
