# Sampling

Type: enum | Package: com.hypixel.hytale.builtin.buildertools.tooloperations

private static enum Sampling

Sampling mode for `RevolveOperation`. `Neighbor` fills gaps by sampling adjacent blocks, `Reverse` uses reverse rotation sampling, `Disabled` performs no gap filling.
