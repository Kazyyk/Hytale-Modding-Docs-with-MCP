# PropRuntime

Type: class | Package: com.hypixel.hytale.builtin.hytalegenerator

public class PropRuntime

Associates a `PropDistribution` with a runtime index for world generation prop placement scheduling. The runtime index determines when during generation the prop distribution is evaluated.
