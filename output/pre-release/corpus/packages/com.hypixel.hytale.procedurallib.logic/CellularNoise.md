# CellularNoise

Type: class | Package: com.hypixel.hytale.procedurallib.logic

public final class CellularNoise

Static lookup table containing 256 pre-computed `DoubleArray.Double2` vectors used as cell jitter offsets by MeshNoise and other cellular noise implementations. Each entry contains x and y values in the range [0, 1). This class has no constructor or methods beyond the constant array.
