# ClimateColor

Type: class | Package: com.hypixel.hytale.server.worldgen.climate | Extends: java.lang.Object

public class ClimateColor

Holds the map visualization colors for a climate type across four terrain categories: land, shore, ocean, and shallow ocean. Each color is stored as a packed RGB integer. Provides sentinel constants for unset, island, island shore, shore, ocean, and shallow ocean colors.
