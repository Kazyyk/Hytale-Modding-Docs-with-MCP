# ClimatePoint

Type: class | Package: com.hypixel.hytale.server.worldgen.climate | Extends: java.lang.Object

public class ClimatePoint

Represents a point in temperature-humidity space that defines where a climate type is centered within the climate graph. Each `ClimateType` has one or more climate points that determine its region in the 2D climate space.
