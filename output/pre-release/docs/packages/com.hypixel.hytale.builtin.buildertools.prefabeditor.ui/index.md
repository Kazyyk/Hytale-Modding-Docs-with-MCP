## Package `com.hypixel.hytale.builtin.buildertools.prefabeditor.ui`

UI pages for the prefab editor builder tool. Each page is a custom interactive UI that renders within the player's HUD during prefab editing sessions.

| Type | Kind | Description |
|---|---|---|
| [PrefabEditorExitConfirmPage](PrefabEditorExitConfirmPage.md) | class | Exit confirmation dialog with unsaved-changes warning. |
| [PrefabEditorLoadSettingsPage](PrefabEditorLoadSettingsPage.md) | class | Full settings form for loading prefabs into an edit session. |
| [PrefabEditorSaveSettingsPage](PrefabEditorSaveSettingsPage.md) | class | Save settings and prefab browser for persisting edits. |
| [PrefabTeleportPage](PrefabTeleportPage.md) | class | Teleport-to-prefab UI with fuzzy search. |
- [PrefabEditorLoadOptionsPage](PrefabEditorLoadOptionsPage.md)
